## Vibe Coding with Claude

AI-assisted development is part of how I work every day — not as a shortcut, but as engineering leverage.

I use [Claude](https://claude.ai) as a pair-programming partner across my workflow: architecture decisions, code generation, refactoring, testing, and documentation. Combined with the [BMAD method](https://github.com/bmadcode/bmad-method) — a structured approach to AI-driven development — this gives me a repeatable process that moves faster without cutting corners.

The result: I ship production-grade software with a small team (or solo) at a pace that used to require much larger squads.

**How it fits into my process:**

| Phase                    | What happens                                                      |
| ------------------------ | ----------------------------------------------------------------- |
| Discovery & Architecture | Claude helps explore tradeoffs, draft specs, validate decisions   |
| Implementation           | Structured prompting via BMAD for consistent, high-quality output |
| Review & Testing         | AI-assisted code review, test generation, edge case analysis      |
| Documentation            | Auto-generated docs that stay in sync with the codebase           |

This isn't "AI writes everything." It's a disciplined workflow where I stay in the driver's seat and AI amplifies what I can deliver.
